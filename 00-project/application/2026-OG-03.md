# Investigation of Optimal Path Planning in Drone Swarms

## My interpretation of the brief
The objective of this project is to build a version-controlled 3D simulation application that models and optimizes formation transitions in a multi-drone swarm. The system must allow users to configure drone counts, movement limits (such as speed and acceleration), and initial versus target positions. Core technical goals include implementing at least two target assignment or path-planning algorithms, handling real-time collision avoidance, and comparative evaluation of strategies based on computational overhead, total flight time, and path distance. Crucially, the simulation and optimization logic must remain decoupled from the 3D visualization.

## Proposed approach
Implement a modular architecture where the core optimization/simulation engine is completely independent of the 3D rendering engine (e.g., C++/Python with a standard 3D visualizer like WebGL, Three.js, or Unity).
Implement two distinct approaches for target assignment and path generation—such as a classic spatial matching/greedy heuristic versus the Hungarian algorithm for global cost minimization.
Model movement constraints (max speed, acceleration) and integrate a continuous spatial collision avoidance mechanism during formation transitions.   
Collect execution metrics for each run, measuring total flight time, combined distance traveled, and algorithm execution runtime across varying drone swarm sizes.

Phase 1 (Weeks 1–3): Finalize project setup, establish the Git repository, define core 3D spatial data structures (drones, formations, vectors), and build basic unit tests.
