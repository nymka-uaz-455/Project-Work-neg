# Study material grounded exircise generation and practice application 

## My interpretation of the brief
My main goal is not simply to generate questions using an LLM, but to ensure that generated questions and answers can be traced back to the original study material. The system must therefore connect documents, source excerpts, questions, reference answers, learner attempts, and exercise results.

## Proposed approach
